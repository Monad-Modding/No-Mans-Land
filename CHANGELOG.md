# New Features
- Added **3 new tools and a block** found in the Alchemist Ruins.
  - **The Ritual Pick**, used to communicate with the earth and receive its messages back through vibrations.
  - **The Ancestral Oath Sword**, a relic bound by a powerful oath of pacifism, a weapon used not to harm others.
  - **The Ancient Bronze Chisel**, an old tool which yet its sculptor's knowledge retains. 
  - **The Ancient Bronze Bell**, a decorative bell whose vibrations can cause light to dance along its will.
- Added 3 new block sets of **Lunar, Solar and Stellar tiles** with their according variants
- Added **Wooden Platform Steps** when Clutter No More is installed
- Added a new painting, **Driftwood**
- Added **Mossy Siltstone Bricks**

## Changes
- Taps can now be turned on and off
- Allowed extinguished torches to be waterlogged

## Fixes
- Fixed an Integrated GPU crash
- Fixed extinguishing and lighting mechanics with many different mods
- Fixed icicles not hitting entities on a mount
- Fixed many actions not making a game event
- Fixed many other miscellaneous bugs
